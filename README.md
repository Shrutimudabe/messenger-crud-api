# messenger-crud-api

## 🚀 Features
- Create, Read, Update, Delete (CRUD) operations
- RESTful API design
- Backend service implementation
- Database integration

##  Tech Stack
- Backend: Node.js
- Database: MongoDB

##  API Endpoints
- POST /create
- GET /messages
- PUT /update/:id
- DELETE /delete/:id

##  Testing
Tested using Postman

## Description
This project demonstrates backend development fundamentals including API design, database handling, and CRUD operations.
